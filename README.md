## Cómo Compilar y Ejecutar
Cada ejercicio está guardado en su propia carpeta y contiene sus archivos independientes (`Nodo.java`, `ListaSimple.java`/`ListaDoble.java` y `Main.java`)[cite: 1].

Para compilar y ejecutar cualquiera de ellos desde tu terminal (por ejemplo, el Ejercicio 2), sigue estos pasos:

1. Entra a la carpeta del ejercicio:
   ```bash
   cd ejercicio2_cuenta_letras_al_vector/

2. Compila los archivos java:
	javac Nodo.java ListaSimple.java Main.java

3.Ejecuta el programa:
java Main
